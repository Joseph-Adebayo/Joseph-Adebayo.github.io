PhishGuard: Checking Links for Phishing

October 2026 · Python, Flask · View the code on GitHub

PhishGuard is a small web app I built in Python and Flask. You paste in a link, and it checks the URL for patterns that are common in phishing links, then lists any red flags it finds.

How It Works

The app uses the tldextract library to split a URL into three parts: the subdomain, the domain and the suffix (like .com or .co.uk). Most of the checks rely on that split, because phishing links often hide a trusted name in the wrong part of the address.

For example, in paypal.secure-login.account.tk the real domain is account.tk, not PayPal. "paypal" is only in the subdomain. This is the check that catches it:

def check_brand(result):
    subdomain = result.subdomain.lower()
    domain = result.domain.lower()
    for brand in SUSPICIOUS_BRANDS:
        if brand in subdomain and brand != domain:
            return True
    return False

The full list of checks:

  • A well-known brand name in the subdomain but not the real domain
  • Top-level domains often used in scams, such as .tk, .xyz and .top
  • Unusually deep subdomains
  • A raw IP address instead of a domain name
  • Lots of hyphens in the URL
  • Digits mixed with a brand name, like paypal123

Limitations

PhishGuard is rule-based, so it only catches the patterns I've written checks for. A clean result doesn't prove a link is safe. Ideas for improving it include detecting lookalike characters (e.g. rn pretending to be m) and checking how recently a domain was registered.
